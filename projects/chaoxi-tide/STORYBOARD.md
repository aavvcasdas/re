# 《潮汐·留灯》分镜

**时长：** 55.983 s · **画幅：** 16:9 · **渲染：** 12 fps / 手绘 on twos · **主节拍：** 70.3 BPM、4/4 感的半拍脉冲，0.430 s 起拍。<br>
**声音：** 用户上传的 `潮汐.mp4` 内嵌音轨，AAC 解码并转为 `assets/song.mp3`。<br>
**分镜原则：** 借参考片的歌词呼吸与情绪曲线；换掉角色轮廓、世界、色彩、主要道具、镜头角度与字幕造型。

## Logline / world / motif

一颗微小的赤陶色潮种在巨大的潮汐图上追寻光线；遇见折纸海燕后，它把所有暖色都交给了记忆。潮水带回贝壳铃，它终于学会把一粒光留给自己。

- **世界：** 像盐蚀版画与纸上潮汐图叠成的海岸档案室。不是球形小行星，而是横向铺开的潮线、浅滩、墨色海沟与折纸页。
- **画法：** 双色套印的平涂剪纸、偏移描边、细密等高线、留白纸纹。冷墨蓝起步 → 海玻璃青与赤陶相遇 → 暴雨灰紫 → 盐珊瑚朱砂 → 暖金留灯。
- **角色：** 赤陶色的“潮种”（梨形种荚，胸口有一粒微光）；灰青色的“折纸海燕”（扇翼和纸纹肋线）。两者的轮廓和来源片中的方盒角色不同。
- **反复母题：** 一条金色等高线；一只扇形贝壳铃；最初只有一串脚印，结尾多出第二条同行的潮线。
- **字幕：** Ma Shan Zheng 字体，浅色撕纸条、墨蓝正文、朱砂逐字套印；不使用参考片的深色字幕牌。

## Cue map

- **音乐网格：** `BEAT = 60 / 70.3 = 0.8535 s`；第一强拍 `0.430 s`。拍序列取自新 MP4 的音轨；歌词点落在 `0, 5, 9, 14, 19, 24, 28, 33, 38, 43, 47, 52, 57` 拍。
- **字幕时间：** 见 `assets/song.lrc` 与 `src/karaoke.js`，逐字套印速度均匀，句末不额外压缩；最后一句结束后留出尾奏。
- **转场：** 每个镜头交界用同一组墨蓝 / 淡纸色的粗笔刷擦幅，建立版画的统一感；镜头内部再用形状匹配和潮线延续做叙事连接。
- **首尾押韵：** 第 1 镜仅有一枚脚印；第 14 镜在相同潮图构图上出现两条并行路线，世界没变小，角色学会与自己和他人同行。
