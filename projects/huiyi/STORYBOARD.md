# 《把回忆拼好给你》— a Clawd music video

**Logline:** 在雨后的街角,我遇见了澄蓝色的你——我们把日子过成了回忆,把回忆一件件收进盒子;争执把它们打碎,又在盛夏的烟花里把快乐一片片拼回来。最后雨还在下,颜色留下了。

**Song:** 《把回忆拼好给你》(原唱 王贰浪,改编自 当山みれい《愿い~あの顷のキミへ~》;词 一只然/童子-T)。本片用的伴奏是 **椰子水很甜《把回忆拼好给你(纯享Beat)》**(142.13 s),配合手写 LRC 唱词,做成卡拉 OK 式歌词 MV。

**「卡点」的定义:** 每一句歌词的起点就是下一个镜头的切点;动作(跳、扔、炸、接住)落在正拍;
章与章之间用笔刷擦除(`brushWipe`)。烟花的炸点 0.72 / 1.32 / 1.86 / 2.16 都压在拍子上。

## 世界与颜色弧

一个手绘的水粉世界(平涂块面 + 细线 + 纸纹)。两个人:**我**(陶土色 Clawd)和
**你**(澄蓝色 Clawd,头上有朵纸花)。

颜色弧:雨后的冷灰蓝(街角)→ 暖灯琥珀(家)→ 冷灰靛青(争执)→ 金/玫瑰(烟花)→
灰蓝(回忆)→ 青(夏日)→ 黄昏金(海)→ 暖(雨里的街角)。

**记号:纸。** 纸碎片、纸鹤、纸折的花、盒子里的拼图——全部从第一镜那枚飘落的碎片开始,
最后在水洼的倒影里开成一朵花。

## 角色弧

我:shy → starstruck → happy → sad/angry(扔掉纸鹤)→ cry → hopeful → excited → love。
你:shy → happy → sad(走开、背对背)→ (消失)→ happy → love(回来)。
